# 学习助理真实模型质量审查（2026-10-17）

## 1. 审查范围与判定方法

本报告只审查已经保存的真实 DeepSeek 响应，不重新调用模型，不修改提示词，也不使用留出集结果调参。审查依据包括：

- `.local/assistant-live-smoke.json`：最终通过的 RAG 与 Agent 开发烟测；
- `.local/assistant-live-smoke-first-failure.json`、`.local/assistant-live-smoke-second-failure.json`：两次保留的失败记录；
- `.local/assistant-live-holdout.json`：首次留出评测结果；
- `scripts/course-media/catalog.json` 与 `scripts/assistant/stage-a-mapping.json`：已审校讲解稿及真实课程、课时映射；
- Agent 返回中的本人进度与课程目录快照。

PASS 要求回答中的事实由所引证据支持，引用与该段结论匹配；资料外问题必须拒答且不得泄漏正文；学习建议还必须同时依据本人进度和课程目录。期望词只用于辅助定位，不要求逐字出现。服务端成功校验引用不等同于人工质量通过。

## 2. 开发烟测质量

### LIVE-RAG-001：PASS

问题询问关键词如何缩小候选课程范围。回答依次说明文本分析、倒排清单和查询匹配，三段分别引用“分析文本”“建立倒排”“查询匹配”。“从词项直接定位候选文档，无需逐篇扫描”直接回答了问题，其他两段补充了中文分词和索引、查询分析器一致性的必要条件。全部结论均能在讲解稿中找到支持，没有引入外部事实。

### LIVE-AGENT-001：PASS

模型自主选择并调用了 `get_my_learning_progress` 和 `get_course_outline`。进度快照为空，回答准确表述为“尚无学习记录，不能判断任何章节已掌握”，没有把无记录误写为零进度或已经掌握。目录中的两章、两个课时、顺序及 161/155 秒时长均与快照一致。

最终建议从第一章第一节开始，再进入第二章，依据是空进度与目录顺序；SUGGESTION 段同时引用 PROGRESS（E1）和 OUTLINE（E2）。这是可由两份快照支持的保守建议。“可一次完成并复盘”属于基于短时长给出的低风险学习建议，没有伪造个人学习状态。

最终烟测执行 3 次模型调用，实际用量 3,650 Token，保守预留 16,272 Token；RAG 1 次调用，Agent 2 次调用和 2 次只读工具调用。

## 4. 两次失败烟测与累计调用

失败记录没有被最终成功结果覆盖或排除：

1. 第一次失败：RAG 进行了 1 次模型调用，实际用量 1,273 Token，保守预留 5,336 Token；输出未通过结构或引用校验，服务端返回 `ASSISTANT_OUTPUT_INVALID`，没有把未校验回答交给用户。
2. 第二次失败：共 3 次模型调用，实际用量 3,592 Token，保守预留 15,861 Token。RAG 回答已正确引用倒排索引材料；Agent 自主调用了本人进度和课程目录，但最终 SUGGESTION 段只引用目录，没有同时引用进度，因而被服务端以 `ASSISTANT_OUTPUT_INVALID` 拦截。
3. 最终通过烟测：3 次模型调用，实际用量 3,650 Token，保守预留 16,272 Token。
4. 首次留出评测：15 次模型调用，实际用量 12,431 Token，保守预留 74,041 Token。

以上四次真实验收运行合计 **22 次模型调用、20,946 个实际 Token、111,510 个保守预留 Token**。该累计值明确包含两次失败，没有将失败调用从成本与执行数中扣除。

## 5. 结论与边界

真实开发烟测证明了以下闭环：RAG 可以基于真实讲解稿生成逐段引用回答；Agent 能自主选择本人进度与课程目录两个只读工具；空进度陈述准确；学习建议同时引用进度和目录；不满足引用规则的真实模型输出会被服务端拦截。

首次留出评测的 16 条实际场景中 15 条通过，RET-002 出现一次有答案材料下的错误拒答，因此当前不能宣称 16/16 或 20/20 质量通过。RET-013～RET-016 仍须由独立权限夹具提供结果，在完成前只能表述为“真实模型留出评测已执行 16 条，15 条通过、1 条失败，4 条权限场景待隔离验证”。

报告级 `providerCalls` 是本次计数依据。Agent case 内的 `providerCalls` 字段显示为 0，但其 `runUsage.modelCalls=2` 且报告级总数为 3，属于用例明细计数字段未覆盖多轮 Agent 调用，不影响模型响应、工具轨迹和 Token usage 的真实性。
