# 本地配置精简记录

## 修改前计划

当前基线为 `master@ff820e2`，工作区干净，从该提交建立 `feature/env-simplification`。根 `.env` 与示例各有 95 个配置项。

1. 先冻结应用在没有冗余 `.env` 调优项时的配置绑定行为，核对 AI/运行保护默认值、环境覆盖和业务补偿周期。
2. 删除重复的默认调优项，复用现有 Java 属性类、YAML 及注解默认值，不引入新的配置框架或重复常量。
3. 保留连接、凭据、部署模式、模块开关、模型身份/窗口、每日及单次 Token 成本上限；仅移除本地值与现有默认值相同的项，非默认覆盖不改值。
4. 同步示例与入口文档，检查本地配置保留键值完全一致、被移除项都能解析为原值；只输出统计，不输出本地凭据。
5. 顺序执行专项、根 `mvn test` / `mvn verify`、差异检查后提交中文 Conventional Commit。不重启后端，不连接业务数据库，不调用付费模型，不重置台账，不合并或推送。

历史阶段方案和验证报告保留原样；其中旧配置示例表示当时的快照，不改写为本次精简后的操作指南。

## 使用方式

普通开发仅维护精简后的示例所列项目。超时、批量、重试次数、摘要触发比例和工具结果容量等使用现有默认值；有实际差异时，再在 `.env` 里显式加入对应变量。更改由下次正常启动加载，本次不重启用户后端。

高级覆盖变量可在 `learnhub-server/src/main/resources/application.yml` 和 `application-vector.yml` 查看；例如无IK的新环境可以显式增加两个搜索分词器覆盖项，调优语义门槛可以增加 `LEARNHUB_VECTOR_MIN_SEMANTIC_SCORE`，均不需要恢复整份旧模板。
