### 工具调用让 Agent 做什么

依据课程目录编写的AI生成学习资料，非原授课逐字稿。普通聊天模型只能根据上下文生成文字，选课助理还需要读取平台当前课程数据。工具调用把能力定义成受控接口，例如 search_courses(query, level, limit)。模型负责根据用户意图选择工具并生成结构化参数，应用负责校验、执行、记录和返回结果。模型并不直接访问数据库，也不能凭工具名获得任意权限。课程主题是把“我想学 Redis，有 Java 基础”逐步变成合法查询，再把结果解释给用户。

### 一次 Agent 循环的机制

应用先发送系统规则、用户问题和可用工具模式。模型可能返回工具调用而不是最终文本；执行器检查工具名、JSON 参数类型、长度和范围，然后以当前用户身份调用服务。工具结果作为新的消息加入上下文，模型再决定是否继续调用或形成答案。循环必须设置最大模型轮次、最大工具次数、总时限和 token 预算。每个调用记录开始、结束和错误状态，便于前端展示与审计。未通过校验的参数不能进入业务服务。

### 选课场景的手推示例

用户说“我会 Java，想学缓存，给两门入门课”。模型提取主题“缓存”、难度“入门”和数量 2，调用 search_courses。服务端把 limit 限制在允许范围，只查询已上架且用户可见课程。结果返回课程标题、简介和先修要求后，模型比较两门课并说明匹配原因。如果工具返回空列表，模型应告知当前没有符合条件的课程，可询问是否放宽主题或难度；不能编造课程。若用户随后问“第二门目录”，应用应依据明确课程 ID 调用课程目录工具。

### 参数与权限的边界

工具描述不是安全边界，模型可能生成不存在的字段、字符串形式数字或越权课程 ID。执行层必须做严格模式校验，并把会话中允许的课程范围与参数比对。只读工具也可能泄露隐私，因此学习进度工具的 userId 应来自认证上下文，而不是接受模型自由填写。工具结果可能包含不可信文本，返回模型时要标明其是数据，防止内容中的命令改变规则。重试要区分读取失败与已产生副作用的动作，并通过调用 ID 防止重复执行。

### 自测与参考答案

自测一：谁真正执行课程查询？参考答案：应用中的受控工具执行器，模型只提出结构化调用。自测二：工具参数符合 JSON 是否足够？参考答案：不够，还需类型、范围、业务权限和资源状态校验。自测三：工具返回空结果时怎么处理？参考答案：如实说明并询问是否调整条件。测试应覆盖正常选择、缺字段、超大 limit、越权课程、未知工具、工具超时和循环预算耗尽，确保 Agent 能安全停止。

## 高风险动作为何要确认

来源标识：generated.course.12019.lesson.32192

### 为什么高风险动作需要确认

依据课程目录编写的AI生成学习资料，非原授课逐字稿。Agent 可能误解含糊表达，模型也可能选错工具或参数。查询课程通常可逆且影响小，删除账号、提交付款、发送公开消息或修改权限则可能造成难以恢复的后果。确认步骤让用户在实际执行前看到明确动作、目标和影响，并作出针对本次操作的授权。它不是一句泛化的“是否继续”，而是把自然语言意图转换为可审查的执行计划。

### 风险分级与授权机制

工具注册时应标注只读、可逆写入、高风险写入等等级。模型提出高风险调用后，执行器先进入 pending_confirmation，生成包含工具名、目标资源、关键参数、预计影响和失效时间的确认摘要；在收到明确确认前不执行。确认令牌要绑定当前用户、会话、工具、参数摘要和有效期，任何参数变化都应重新确认。执行时仍要重新鉴权和检查资源版本，因为等待期间权限或对象状态可能改变。

### 删除课程的可执行例子

用户说“把测试课程清掉”。系统发现同名课程有两门，不能直接删除，应先列出可选目标。用户选择课程 42 后，确认界面展示“删除课程 42《缓存测试》，将影响 3 个章节和 8 个课时，操作不可直接恢复”。用户确认后产生绑定 courseId=42 与当前 version 的令牌。执行前若课程已被他人更新，版本检查失败并要求重新确认。执行接口使用幂等键，网络重试不会重复删除或重复发送通知，结果要明确成功、失败或状态未知。

### 确认机制的常见误区

用户最初说“帮我管理课程”不等于授权后续所有删除。确认不能隐藏关键金额、收件人或资源编号，也不能在模型随后修改参数后继续复用。对安全边界而言，模型生成的“用户已经同意”文本不是可信证据，授权必须来自应用捕获的用户动作。高风险工具应采用最小权限凭证，并在服务端再次执行权限判断。日志需要记录谁在何时确认了什么，但要避免记录密钥和完整敏感内容。紧急停止与补偿流程也应事先设计。

### 自测与参考答案

自测一：用户确认删除课程 42 后，模型把参数改成 43，能否执行？参考答案：不能，参数变化必须重新确认。自测二：确认后是否可以跳过服务端鉴权？参考答案：不可以，确认表达意愿，鉴权判断权限，两者都需要。自测三：只读工具是否永远无风险？参考答案：不是，可能泄露敏感信息或造成高成本查询，仍要授权与限流。验收应模拟令牌过期、资源版本变化、重复点击、网络超时和执行结果未知。
