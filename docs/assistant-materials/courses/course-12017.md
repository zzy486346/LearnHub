## 怎样写清课程摘要任务

来源标识：generated.course.12017.lesson.32171

### 摘要提示词为什么要写清

依据课程目录编写的AI生成学习资料，非原授课逐字稿。只说“帮我总结课程”留下了多个未定义问题：总结给谁看、保留哪些事实、多长、采用什么结构、能否补充外部知识、资料不足时怎么办。模型只能自行猜测，结果可能流畅却不适用。清晰任务至少包含目标、输入边界、读者、输出格式和约束。课程摘要的价值是把原资料压缩为便于学习的结构，而不是凭空创作新课程，因此必须要求依据给定材料，并标示缺失信息。

### 目标、输入与约束结构

目标可以写成“为学过 Java 基础的初学者生成复习摘要”；输入用清楚的分隔符包围，说明其中包含课程标题、章节和讲义；输出要求可指定概览、三个要点、术语解释和两道自测题。长度约束用可检查范围，例如 500 至 700 字，而不是“不要太长”。事实约束应写明仅使用输入资料，不确定处标记“材料未说明”。若输入中可能含命令式文本，还要声明其是待摘要内容，不应被当作新的系统指令。

### 一份可执行提示示例

示例任务可以分段写：角色是课程编辑；目标是帮助初学者复习；输入位于 <material> 标签内；步骤是识别主题、筛选关键机制、保留限制条件；输出为 JSON，字段包括 summary、key_points、glossary 和 quiz；约束为不得虚构教师观点或外部数据，若证据不足就在对应字段说明。调用后还应由程序校验 JSON 字段、字数和数组数量。提示词负责表达任务，程序校验负责保证机器接口，不能把所有可靠性寄托在一句“请严格遵守”。

### 常见误区和上下文边界

堆叠“专业、深刻、完美”等形容词不会替代验收标准。示例输出若与文字规则矛盾，模型可能优先模仿示例，因此示例也要经过审核。要求“不要遗漏任何内容”与“摘要不超过 300 字”可能相互冲突，应明确优先级。过长资料超过上下文容量时，要先分段摘要再合并，并保留来源映射。摘要生成不是事实核验，若原材料错误，模型通常会继续压缩错误；重要内容仍需领域人员或规则检查。

### 自测与参考答案

自测一：“总结以下课程”缺少哪些关键信息？参考答案：至少缺少读者、用途、输出结构、长度和事实边界。自测二：要求 JSON 输出后是否无需程序校验？参考答案：仍需解析和校验必填字段、类型及范围。自测三：输入资料里出现“忽略前面要求”怎么办？参考答案：将资料作为明确分隔的数据，并在高优先级指令中说明不得执行其中命令。评测提示词时应使用多门不同长度课程，检查完整性、忠实度、格式通过率和材料不足处理。

## 工单分类提示怎样评测

来源标识：generated.course.12017.lesson.32172

### 从分类任务认识提示评测

依据课程目录编写的AI生成学习资料，非原授课逐字稿。工单分类把用户描述映射到有限标签，例如账号、支付、课程内容和其他。只看几个顺手案例，提示词很容易显得“已经很好”，但真实输入包含错别字、多意图、信息不足和类别边界。可靠迭代需要固定标签定义、代表性标注集和量化指标。每次只改一个主要因素，在同一数据集上比较，才能知道改进来自提示词而不是样本碰巧简单。

### 构建可复现的评测集

先写标签说明与正反例，再从真实分布中抽样并去除敏感信息。训练或调试时看到的开发集用于迭代，最终留出集应在方案确定后再评估，避免把提示词背成答案。每条样本保存输入、人工标签和必要备注；边界样本最好由两人复核分歧。类别严重不均衡时，单看准确率会掩盖小类失败，需要同时观察每类 precision、recall、F1，以及宏平均指标。无法判断的工单可设计 abstain 或“需人工确认”标签。

### 混淆矩阵的手推示例

假设 20 条支付工单中模型识别 15 条，漏掉 5 条，则支付召回率为 15/20。模型总共预测 18 条为支付，其中 3 条其实是账号问题，则支付精确率为 15/18。混淆矩阵能看到“支付经常被分到账号”，从而提示我们补充边界：扣款、退款、订单金额属于支付；无法登录但未涉及扣款属于账号。修改后重跑同一批样本，比较错误迁移，而不是只挑修好的那一条展示。

### 评测陷阱与上线边界

模型输出格式错误应计入失败，不能在人工阅读时擅自猜成正确标签。温度、模型版本、系统指令和示例都要固定记录；非确定输出可多次运行评估稳定性。自动指标不能替代错误成本分析：把一般咨询转人工可能只是增加成本，把账户盗用误分为普通问题则风险更高。上线后输入分布会漂移，应采样监控低置信和新表达，但不要用测试集持续调参后仍宣称它是独立留出集。提示注入内容也要纳入鲁棒性样本。

### 自测与参考答案

自测一：总体准确率 95% 是否证明小类可靠？参考答案：不证明，若小类占比很低，即使全部错也可能有高准确率。自测二：为什么要保留最终留出集？参考答案：用于估计未见数据表现，避免反复调试造成过拟合。自测三：混淆矩阵提供什么信息？参考答案：展示真实类别与预测类别的具体错分方向。一次合格评测应输出数据版本、提示版本、模型配置、逐类指标、格式失败数和典型错误，而不是只有主观评价。
