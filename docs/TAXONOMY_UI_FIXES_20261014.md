# 分类筛选与后台弹窗布局修复

- 日期：2026-10-14。
- 分支：`feature/taxonomy-ui-layout`，从当前 `master` 创建。

## 改动

- 课程分类改为可搜索、可清空的紧凑下拉框，保持分类 ID 字符串往返；不删除数据库分类。
- 技能标签默认隐藏，通过“更多筛选”展开可搜索的多选框；选中标签折叠显示，并在按钮上保留数量提示。分类与标签不再以整页按钮云铺开，筛选区独立放在课程标题下方。
- 后台“创建优惠券”“分类与标签”使用白底深色文字；“新建课程”使用深底白字。浏览器读取的前两项为 `rgb(29,33,41)` 文字与白色背景，主按钮采用相反配色，均无渐变背景。
- 分类管理改为有名称、排序、状态标签的表单，操作按钮独立一行；数字输入和下拉框服从容器宽度，解决固定组件宽度覆盖相邻控件的问题。
- 分类与标签弹窗在宽屏中双栏、窄屏中单栏；弹窗限制可视高度，正文和长标签列表可滚动。长标签名称允许换行，删除按钮使用更深的文字颜色。
- 优惠券弹窗正文可滚动，窄屏日期输入服从表单宽度，底部操作保持可见。
