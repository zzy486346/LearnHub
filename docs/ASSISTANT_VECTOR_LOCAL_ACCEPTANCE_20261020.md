# 本地课程向量库、全量回填与冻结题集评测

日期：2026-10-20。分支：`feature/assistant-rag-agent`。保持 JDK 17 / Spring Boot 3.3.5。

## 实际部署与数据边界

课程库已部署到 Docker Compose 的 `deploy` 项目，容器为 `deploy-course-vector-pg-1`，持久卷为 `deploy_course-vector-data`，只发布 `127.0.0.1:15432`。镜像固定为 pgvector 0.8.7 / PostgreSQL 16 的 digest，见 `deploy/docker-compose.vector.yml`。Docker Desktop 的 internal 网络没有提供宿主机端口映射，已增加仅供该容器使用的桥接网络；最终宿主机 TCP 与实际 JDBC 均通过。

课程向量库 `learnhub_vector` 与 Mem0 的 PostgreSQL 数据库分开，不混用记忆表。运行账号仅有课程投影表 DML、schema USAGE 和数据库 CONNECT；无超级用户、创建数据库、角色或 schema 权限。管理员密码与运行密码只读本地 `.env`，未写入报告或提交。

全部 24 门课程的既有生成讲义已被使用：51 份生成资料与原有 6 份资料，共 57 份当前文档、273 个知识片段，回填为 273 条 512 维向量。模型为本地 `bge-zh-v15-q-lc122-t480-o32-v1`，精确余弦检索，未使用近似索引；没有外部 Embedding 或生成模型调用。

MySQL 仍是正文、权限和版本的事实源；ES 和 PG 均为可重建投影。回填复用 `VectorProjectionSync` 的代次复核、锁与补偿；重复同步无新编码或新向量。增强复核会比较 MySQL 与 PG 的文档/版本/片段精确身份集合，并对全部文档及全部片段字段取前后快照，拒绝仅凭向量总数认定完整。

## 首轮冻结评测

在检索执行前提交题集 `30f656e`，文件为 `assistant-retrieval-local-20261020.json`。共 72 题：48 道可回答题（24 门课程各 2 题）、12 道资料不足题、12 道跨课程题。首轮原始回执为 `assistant-vector-local-first-20261020.json`，保留不覆盖，不根据成绩调整题目。

三路分别执行相同 72 题，共 216 次检索；单路候选上限 100，返回最多 5 个知识片段，RRF k=60。查询顺序逐题轮换，延迟含权限和版本读取，模型初始化预热不计入。使用真实现有用户的授权，不添加购买记录；另外执行 21 次真实不可读课时排除检查，未发现越权。

这是新问题对既有生成讲义的来源级评测，来源标签按文档判断，@5 位置按片段计算；不是未见文档泛化、人工答案评分或真实流式回答验收。首轮排序略有改善，同时延迟上升。资料不足题仍全有弱召回，所以保留混合检索默认关闭，不能宣称答案质量已经提高或问题可以全部回答。

评测执行器在审查后加强了预期课时授权选择、精确代次集合、全字段快照及首轮文件原子写入。增强后的复核沿用冻结题集和算法，归档回执见 `assistant-vector-local-verified-20261020.json`，后续最新回执写入 `.local/vector-local-latest.json`；首次回填编码 273 次，重复同步编码为 0。失败尝试中曾发现宿主端口未映射，以及快照新增日期字段需要 Jackson 时间模块；均已修复后重跑。

启动课程库和复跑回填的完整命令见 `deploy/README.md`。本机 `.env` 已包含 `local,vector` profile，启用向量连接与增量同步，保留 `LEARNHUB_VECTOR_HYBRID_ENABLED=false`。已增加 ConfigData 测试，证明从导入的 `.env` 属性读取 profile 能加载向量配置，避免仅填写大写变量却没有启用 profile。
